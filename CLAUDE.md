# Website 2.0

React + Vite + Tailwind CSS personal portfolio site, deployed to Cloudflare Pages.

## Commands

- `npm run dev` — dev server
- `npm run build` — production build to `dist/`
- `npm run lint` — ESLint (zero-warning policy)
- `npm run deploy` — build + deploy to the `logan-website` Cloudflare Pages
  project (production domain: logankm.com)

Deploying requires Wrangler auth (run in an interactive terminal — Claude cannot auth):

```
wrangler logout && wrangler login   # if authed to the wrong account
npm run deploy
```

The site is **not** on GitHub Pages.

## Architecture

All site content (bio, education, experience, projects, skills, books, clocks,
nav sections) lives as plain data in `src/data/` — edit those files to change
content; the components are presentation only.

- `src/pages/` — one component per route: `Home` (`/`, video intro overlay +
  portfolio), `About` (`/about`, portfolio with static banner), `Classic`
  (`/classic`, the old three.js soccer scene; lazy-loaded so three.js stays
  out of the main bundle)
- `src/components/Portfolio.jsx` — composes all sections; shared by Home and About
- `src/sections/` — Hero, Education, Experience, Projects, Skills, Contact
- `src/components/widgets/` — hero dashboard widgets (RecentReads,
  CurrentProjects, WorldClock, NavigationWidget); shared chrome in
  `WidgetHeader.jsx` and the `card-glass` CSS class
- `src/components/intro/` — desktop (click) and mobile (swipe-up) intro overlays
- `src/hooks/` — `useMediaQuery`, `useCarousel`
- `src/models/Soccer.jsx` — generated by gltfjsx, hand-tweaked; excluded from
  ESLint, don't reformat
- `private/` — gitignored, never deployed; local-only files live here

Repeated card styles are Tailwind component classes in `src/index.css`:
`card-light`, `card-glass`, `bg-page`, `skill`.

## Conventions

- Assets in `public/` are referenced by absolute path strings (`/images/...`).
  Only referenced assets are kept — if you add a reference, add the file.
- No test suite; verify changes with `npm run lint && npm run build` and a
  manual check of `/`, `/about`, and `/classic` (desktop + mobile widths).
